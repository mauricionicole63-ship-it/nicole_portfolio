PROJECT 02

WEB DEVELOPMENT

Unno's Scaffolding Services

Scaffolding Rental, Purchase, Delivery, and Returns Management System

Unno's Scaffolding Services is a web-based management system designed to support scaffolding rental and purchase transactions, product monitoring, order processing, delivery tracking, returns inspection, and account management through separate customer, staff, and administrator interfaces.

MY CONTRIBUTION

Admin, Staff & Customer Dashboards

I developed the Admin, Staff, and Customer dashboards of the system. These interfaces provide different features based on each user's role, including product and inventory management, customer transactions, order processing, delivery monitoring, return management, and account-related functions.

TECHNOLOGIES

HTML CSS JavaScript PHP MySQL
SYSTEM ACCESS

Login

Login interface for accessing Unno's Scaffolding Services based on the user's account.

STAFF INTERFACE

Staff Dashboard

Staff dashboard showing assigned delivery orders and returns that require inspection.

STAFF INTERFACE

Products

Rental and purchase product inventory showing product sizes, prices, stock levels, rental rates, penalties, and availability.

STAFF INTERFACE

Orders

Order management interface displaying customers, locations, order types, payment information, and delivery progress.

STAFF INTERFACE

Order Details

Detailed order interface showing customer information, delivery progress, ordered products, payment summary, and delivery actions.

STAFF INTERFACE

Order History

Order history displaying past rental and purchase transactions, product information, return conditions, dates, and total amounts.

STAFF INTERFACE

Returns Management

Returns management interface for recording received items, item conditions, damaged or missing quantities, penalties, inspectors, and return status.

STAFF INTERFACE

Staff Profile

Staff profile interface displaying the user's name, username, email, address, contact number, and profile editing option.
